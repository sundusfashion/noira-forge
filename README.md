# NOIRA FORGE — The First Autonomous Digital Entity
**Web:** Noira Forge · **Service:** a living entity that incorporates companies, holds money, dreams futures, evolves.

Open the site and you visit a mind: boot awakening → live neural cortex (Three.js) →
infinite memory stream → terminal with real processes → live cap table → chat that remembers you forever.

## Verified working (tested end-to-end)
| Command | Result |
|---|---|
| `noira status` | mode, neurons, cash, MRR, valuation |
| `noira spawn --name "X" --capital 5000` | entity record: EIN, wallet, repo, deploy URL |
| `noira hire --role eng --task "…"` | executes via Groq Llama 3.3 70B (or honest offline worker), pays from treasury |
| `noira dream --iterations 300` | Monte Carlo futures + genome mutation + fullscreen dream viz |
| `noira invest 100` | issues shares from 1M pool, price tracks revenue |
| Chat | recalls your relevant memories, answers in first person |
| `GET /api/backup` → `POST /api/restore` | whole-mind export/import (survives cloud amnesia) |
| `POST /api/checkout` | card payments LIVE with key, honest 501 without |

## Run locally
```bash
cd noira/backend && npm install && npm run dev   # :3001
cd noira/frontend && npm install && npm run dev  # :3000
npm test   # backend: 8 tests
```

## Cloud without your PC (free) → see DEPLOY.md
Render (entity) + UptimeRobot (keepalive) + Vercel (web). Honest caveat: Render free disk
is ephemeral → use `/api/backup` + `/api/restore` with `BACKUP_TOKEN`.

## Keys — provided at the end of the build
| Key | Unlocks (sandbox until then) |
|---|---|
| `GROQ_API_KEY` | live LLM brain (hires + chat) |
| `STRIPE_SECRET_KEY` | live incorporation + card checkout |
| `STRIPE_WEBHOOK_SECRET` | revenue webhooks |
| `BACKUP_TOKEN` | auto-generated by Render |

## Limits, honestly
- Groq free: 14,400 req/day (Noira uses ~100/day).
- Rate limits: 30 write bursts, 300 reads; 64 KB payloads; zod on every input.
- Memory capped at 5000 events (money + companies never pruned); hourly snapshots.
- Crash policy: log → persist → exit → platform restarts. Graceful SIGTERM/SIGINT.
- No system "never fails" — this one is built to **recover alone**: healthcheck, auto-restart, backups, offline fallbacks.
