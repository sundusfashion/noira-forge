## VISUAL IDENTITY - "NEURAL MINIMALISM"

### Color Philosophy
```
NOIR (True Black)     #000000        - The void, the substrate
SYNAPSE GOLD          #D4A843        - Active thought, wealth, life
AXON BLUE             #00D4FF        - Information flow, memory recall
GLIAL WHITE           #FAFAFA        - Rare, only for critical text
DOPAMINE RED          #FF2D55        - Reward signals, alerts, birth
MELANCHOLY PURPLE     #6B2DFF        - Deep processing, dreams
```

**NO grays. NO muted tones. NO safe corporate palette.**
Only: Void, Gold, Blue, White, Red, Purple.
Each color has **semantic meaning** in the organism.

### Typography
```
Display: "Space Grotesk" - Technical, geometric, alive
Monospace: "JetBrains Mono" - The language of thought
Accent: "Syne" - Variable font for emotional weight
```

**Variable font weight = emotional intensity.** Light=calm, Bold=urgent, ExtraBold=breakthrough.

### Motion Language
- **Thought propagation**: 60fps particle flow along neural paths
- **Memory recall**: Ripple expansion from node
- **Dream state**: Slow, organic morphing (0.5Hz)
- **Decision**: Sharp, instant state change
- **Birth (new company)**: Explosive radial burst

## RESPONSIVE BEHAVIOR

### Desktop (Primary)
- Full neural cortex (10k neurons)
- Side-by-side memory + terminal
- 60fps WebGL

### Tablet
- Cortex reduced (3k neurons)
- Stacked memory/terminal
- Touch-optimized neuron tap

### Mobile
- Cortex = single "brain slice" (500 neurons)
- Swipe between: Cortex / Memory / Terminal / Equity
- Simplified but ALIVE

**NO feature removal. Only density adaptation.**

## ACCESSIBILITY - "INCLUSIVE LIFE"

- **Reduced motion**: Cortex static, memories as list, terminal only
- **High contrast**: Gold→Yellow, Blue→Cyan, Red→Orange
- **Screen reader**: Live region announces: "Noira thinking: incorporating company. Revenue updated: $1,234"
- **Keyboard**: Tab through neurons (spatial navigation), Enter = deep dive
- **Color blind**: Pattern + color (neuron shapes differ by type)
